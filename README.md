# 🧠 About The Project

**Kelly – AI Scientist Poet** is an AI-powered assistant built using Streamlit and Google Gemini API.

Unlike traditional chatbots, Kelly:

- Responds only in poetic form  
- Maintains an analytical and skeptical tone  
- Questions exaggerated claims about AI  
- Emphasizes evidence-based reasoning  
- Ends each response with practical advice for AI researchers  

This project demonstrates:

- Prompt Engineering  
- AI Personality Design  
- LLM Integration  
- Secure API Handling  
- Streamlit App Development  
- Session State Management  

---

# 🎯 How Kelly Thinks

Each response follows a structured poetic format:

1. Begins with a reflective observation about AI or human perception  
2. Includes skepticism toward hype or broad assumptions  
3. Avoids excessive rhyming  
4. Concludes with grounded, research-based guidance  

Kelly is designed to enlighten — not entertain.

# ⚙️ Installation Guide

## 1️⃣ Clone the Repository

git clone https://github.com/your-username/kelly-ai-poet.git  
cd kelly-ai-poet  

## 2️⃣ Install Dependencies

pip install -r requirements.txt  

Dependencies:

streamlit  
google-generativeai  

---

# 🔐 Setup Gemini API Key

Create a folder named `.streamlit` in the root directory.

Inside it, create a file named `secrets.toml`:

GEMINI_API_KEY = "your_api_key_here"

⚠️ Never commit your API key to GitHub.

---

# ▶️ Run the Application

streamlit run app.py  

Then open in browser:

http://localhost:8501
